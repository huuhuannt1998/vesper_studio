VESPER Studio

Starting VESPER on this computer…

VESPER Studio is the window; VESPER itself runs from its Python package. Install it once (on Windows, inside WSL2), then open the app again:

uv tool install vesper-studio      # or, from the source: uv tool install .
vesper catalog fetch <bundle> --sha256 <hash>   # or: vesper catalog sync && vesper catalog build
vesper doctor

Set VESPER_BIN to the vesper command if it is somewhere else.
