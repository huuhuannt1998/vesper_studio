Rooms

Claude reads the rooms, doors and entrance from a floor-plan image; check them over the image here, then generate. The image goes to Anthropic through your Claude Code session. A vesper-plan/1 file is read here, with no Claude.

One storey: when a plan draws several floors, only the floor with the main entrance is read. A balcony, terrace or patio is built outdoors, like a porch. What the plan's walls cannot carry (a window on no outside wall, a door wider than its wall, a door between rooms that do not touch) is left out or narrowed and listed under Problems as a warning; nothing is invented.
